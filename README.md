# Denys Tereshchenko — CV Website

Персональний сайт-резюме, зверстаний на HTML та CSS за макетом, створеним у Figma.

- **Макет у Figma (прототип):** https://www.figma.com/proto/GzUi1x5sZuPS81Dm0AnAQx/Denys-Tereshchenko---CV-Website
- **Мова контенту:** англійська

## Структура проєкту

```
cv-website/
├── index.html                  # розмітка сторінки
├── css/
│   └── style.css               # усі стилі та медіазапити
├── images/
│   └── denys-tereshchenko.jpg  # фото для першого екрана
└── README.md
```

## Що реалізовано

- **Семантичні теги:** `header`, `nav`, `main`, `section`, `article`, `figure`, `address`, `footer`, `time`, списки `ul/li`, ієрархія заголовків `h1–h4`.
- **Коментарі** в HTML та CSS пояснюють кожен блок сторінки й ключові прийоми верстки.
- **CSS-змінні** для кольорів палітри (Petrol blue `#326586`, Sand mist `#F4E9D4`) та розмірів.
- **Сучасна верстка:** CSS Grid і Flexbox, фіксована (sticky) шапка, плавна прокрутка до розділів.
- **Адаптивність:** три медіазапити (≤1100 px, ≤900 px, ≤560 px); на планшетах і смартфонах меню перетворюється на «бургер» без JavaScript (прийом із прихованим чекбоксом).
- **Інтерактивність:** ефекти наведення на кнопках, пунктах меню та картках; кнопка Download CV відкриває PDF-версію резюме; посилання на LinkedIn, email і телефон.

## Як переглянути

Відкрити файл `index.html` у браузері або перейти на сторінку GitHub Pages цього репозиторію.
